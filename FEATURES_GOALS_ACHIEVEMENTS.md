# Система Целей и Достижений

## Обзор функционала

В проекте реализована полнофункциональная система постановки целей и получения достижений для мотивации пользователей.

## 🎯 Цели (Goals)

### Функционал целей:
- **Создание целей** с различными типами (семестровые, месячные, недельные, персональные)
- **Отслеживание прогресса** с визуальными индикаторами
- **Редактирование целей** через модальные окна
- **Автоматическое обновление статуса** по достижении целевого значения
- **Статистика целей** на главной странице

### Типы целей:
- **Семестровые** - долгосрочные цели на весь семестр
- **Месячные** - цели на месяц
- **Недельные** - краткосрочные цели на неделю  
- **Персональные** - пользовательские цели с произвольным периодом

### UI/UX:
- Красивые карточки с градиентами и анимациями
- Цветовая кодировка по статусу (активные, выполненные, просроченные)
- Прогресс-бары с процентным индикатором
- Кнопки для быстрого изменения прогресса (+1/-1)
- Responsive дизайн для всех устройств

## 🏆 Достижения (Achievements)

### Функционал достижений:
- **Автоматическое получение** при выполнении условий
- **Различные типы условий** для получения достижений
- **Система очков опыта** за каждое достижение
- **Визуальное отображение** прогресса к получению
- **История получения** с датами

### Типы достижений:
- **tasks_completed** - за количество выполненных задач
- **tasks_created** - за количество созданных задач  
- **streak_days** - за количество дней подряд с выполненными задачами
- **goals_completed** - за количество достигнутых целей

### Базовые достижения:
1. **Первые шаги** 🎯 - Создайте первую задачу (10 очков)
2. **Отличный старт** ⭐ - Выполните 5 задач (25 очков)
3. **Продуктивный студент** 🏆 - Выполните 20 задач (50 очков)
4. **Мастер планирования** 👑 - Выполните 50 задач (100 очков)
5. **Постоянство** 🔥 - Выполняйте задачи 7 дней подряд (30 очков)
6. **Целеустремленность** 🎪 - Достигните первой цели (40 очков)

## 🔄 Автоматическая система

### Проверка достижений происходит при:
- Создании новой задачи
- Завершении задачи
- Создании новой цели
- Обновлении прогресса цели
- Завершении цели
- Выполнении шага задачи

### Интеграция в приложение:
- **Главная страница** - быстрые ссылки и статистика
- **Навигационное меню** - прямые ссылки на цели и достижения
- **Карточки статистики** - отображение количества достигнутых целей и очков опыта

## 📱 Интерфейс

### Страница целей (/goals):
- Список всех целей с фильтрацией по статусу
- Модальное окно для создания/редактирования целей
- Визуальные индикаторы прогресса и статуса
- Быстрые действия для обновления прогресса
- Статистика по всем целям

### Страница достижений (/achievements):
- Сетка всех доступных достижений
- Индикация полученных/неполученных достижений
- Прогресс-бары для недостигнутых целей
- Общая статистика очков опыта
- Информационные подсказки

### Главная страница:
- Быстрые действия для создания целей
- Карточки статистики с количеством достигнутых целей
- Карточка с общими очками опыта и количеством достижений
- Навигационные ссылки в меню

## 🎨 Дизайн

### Цветовая схема:
- **Цели** - Зеленые градиенты (от emerald до green)
- **Достижения** - Желто-оранжевые градиенты (от yellow до orange)
- **Выполненные цели** - Зеленые оттенки с акцентами
- **Просроченные цели** - Красные оттенки для привлечения внимания

### Анимации и эффекты:
- Hover эффекты на карточках
- Плавные переходы между состояниями
- Анимированные прогресс-бары
- Bounce анимации для новых достижений

## 🛠 Техническая реализация

### Backend:
- **Модели** - Goal, Achievement, UserAchievement в `models/goal.py`
- **CRUD операции** - в `crud/goal.py` и `crud/achievement.py`
- **API endpoints** - в `endpoints/goals.py` и `endpoints/achievements.py`
- **Автоматическая проверка** - интегрирована во все создающие/обновляющие endpoints

### Frontend:
- **TypeScript интерфейсы** - в `lib/api.ts`
- **React компоненты** - страницы в `app/goals/` и `app/achievements/`
- **Модальные окна** - для создания/редактирования целей
- **API интеграция** - через axios с автоматической авторизацией

### База данных:
- **Таблицы** - goals, achievements, user_achievements
- **Связи** - через foreign keys с пользователями
- **Миграции** - автоматические через Alembic
